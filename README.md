# Cloud Computing Lab — GitHub Practical

## Purpose
The purpose of this lab is to understand how GitHub supports cloud-based development, version control, collaboration, automation, and website hosting.

## Lab Activities
- Create and manage a GitHub repository.
- Use Git commands to clone, stage, commit, pull, and push changes.
- Create branches and submit Pull Requests.
- Publish a static website using GitHub Pages.
- Automate a basic workflow using GitHub Actions.
- Use Issues and documentation for project collaboration.
